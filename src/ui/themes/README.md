# 卡片界面与主题

两个已有设置 ID `bubble` / `terminal` 保留，分别呈现“卡片 · 舒适”和“卡片 · 紧凑”。两者继承同一个 CardTheme，只有外观与密度差异，不复制执行状态或渲染逻辑。

## 数据与组件

- `runtime/RunController`：拥有执行状态、检查点与临时 RunLiveState。消息前缀在插件层积累，关闭视图不取消执行。
- `chat-cards/presenter.ts`：把消息、运行记录及实时状态投影成 ChatCard / ChatViewState。ChatPresenter 缓存已结束历史；不修改业务记录，不扫描日志驱动页面。
- `chat-cards/card-list.ts`：按稳定 ID 更新卡片。标题、正文、详情和动作分别更新；保留原生 details、焦点与问答草稿。异步 Markdown 渲染使用版本隔离和独立 Component 生命周期。
- `chat-cards/theme.ts`：统一页头、状态栏、引用文件、卡片列表和输入框。首次显示最新 150 张卡片，按需加载较早记录，更新时保留阅读锚点。
- `chat-view/index.ts`：订阅、输入和用户操作；从运行控制器读取状态，处理审批、恢复、核对及打开文件。

## 视觉规则

所有内容都是单列卡片：左侧 3px 彩色 border 位于同一坐标，无圆点、头像轨道或独立时间线。用户蓝色，模型活动/过程紫色，工具青色，回复/产物绿色，人工交互和未知结果琥珀色，失败红色。正文保持正常文字颜色，同时用标签表达状态，不只依靠颜色。

修改外观请编辑 `chat-cards/style.css`。主题不能从文本猜测操作成功，也不能调用执行、审批或恢复。
