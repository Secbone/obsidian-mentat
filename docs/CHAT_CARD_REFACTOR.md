# 聊天卡片重构

## 范围

统一单列卡片、分段彩色左边框和卡片生命周期；没有圆点。保留现有会话、运行快照、工具权限、审批校验和 DeepSeek 推理/输出配置。

固定卡片类型：用户输入、模型活动、处理过程、工具操作、人工交互、正式回复、校验产物、系统结果。错误是原卡片的状态；无具体归属的错误才单独显示系统卡片。

## 状态契约

RunController 继续是生命周期和操作结果的唯一权威。RunLiveState 只保留临时前缀、当前阶段和停止中的显示状态；不新增持久化状态机。BaseAgent 的流增量包含完整累计前缀，页面重开时可从控制器恢复。

ChatView 订阅在读取历史之前建立；真正渲染时重新对照最新运行和实时状态。按 sessionId/runId/agentId 过滤旧任务及子任务事件。agent:end 不提前完成页面任务；完成由控制器提交后的状态决定。首次附着只选择最新运行，不跳过已完成运行去寻找旧失败。

实时、恢复和历史回放使用同一个投影器。工具由 operationId 关联，并以 OperationRecord/result 为准；旧文本结果无法确认时显示“结果待核对”，不因字符串不像 Error 就声称成功。

## 交互

- 顶部状态栏显示当前活动/等待阶段，已持续时间从该阶段开始计算，不把恢复前的离线时间当执行耗时。
- 运行中发送按钮明确显示“补充指令”；等待审批、回答、结果核对或停止中禁用提交，但保留草稿编辑。
- 审批及问答在对应卡片处理；提交过程中禁用重复动作，后端仍执行状态/指纹校验。
- 从检查点恢复及未知结果核对遵循原控制器规则。核对使用明确输入流程，不自动重放写入。
- 新任务开始失败保留草稿；切换外观保留输入；输入监听在换装和关闭时清理，中文 IME 确认不触发发送。
- 卡片原位更新，不在结束时删除流式块重建历史。独立工具详情、问答输入、焦点和滚动位置在无关更新时保留。
- “查看详情”位于标题行右侧，在原卡片内部展开；收起时不单独占行。宿主背景透明，只保留一层内容缩进，彩色左边框之间留 4px 空隙。
- 产物卡片来自 artifact:verified 事件，可打开文件；不把模型声称“完成”当作校验事实。

## 性能与边界

消息增量合并到约 100ms 刷新；实时事件过滤不执行整段历史投影。已结束历史复用卡片对象。长历史首次显示最新 150 张卡片，每次加载较早 100 张；用户向上阅读后保持锚点，提供“回到最新”。

基于本地 102 条消息、196 张卡片的会话做只读投影测试：无缓存中位约 16.5ms；缓存后的静态投影中位约 0.002ms；模拟新增流式内容中位约 4ms、p95 约 7.2ms。这是数据投影测试，不代表整页渲染、模型或工具耗时。

不显示供应商内部思考正文。活动卡片展示供应商进展、等待或生成阶段。工具详情脱敏并限制大小。旧版未保存的推理进展无法补全。当前长历史采用分批加载，尚非完整虚拟列表。
